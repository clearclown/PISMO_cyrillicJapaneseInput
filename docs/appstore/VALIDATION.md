# 検証記録

2026年9月29日更新。Xcode 26.3、iOS 26.2 SDKで検証しました。対応OSはiOS / iPadOS 17.6以降です。

## 成功した検証

- 文字変換の単体テスト：14件。アラビア文字・ペルシャ文字・注音、結合文字、複合音、連続入力、編集時の入力範囲を確認。
- iOS入力処理の結合テスト：5件。3配列から「にほん」「日本」への変換、削除、配列切り替え、キリル文字の促音を確認。
- 既存の変換テスト：9件。全文・逐次・削除を伴う変換と精度評価を確認。大規模な外部Mozc評価データのベンチマークは対象外。
- 辞書テスト：4件。必須語、禁止語、部分一致、複数の辞書項目から作る「的な」の候補を確認。
- iPhone 17 Pro MaxとiPad Pro 13インチのガイド画面で、3配列の入力例と出力を確認。iPadは横画面も確認。
- アイコン・同梱辞書・モデルのチェックサム・プライバシー申告・iPad画面設定など、ローカルの提出前チェック25項目を確認。
- Apple Development署名付きReleaseアーカイブを作成。
- 06:05の再試行でApp Store向けIPAの書き出しに成功。本体・キーボード拡張とも配布用プロファイルと署名を検証し、デバッグ権限が無効であることを確認。

テスト結果はローカルの`build/`に保存しています。`DictionaryReleaseChecks.xcresult`は辞書・結合テスト、`iPhoneReleaseChecks.xcresult`は変換テストと画面テストの記録です。後者には、その後修正して再検証した旧辞書テストの失敗も含まれます。最終画面のテストは`FinalGuides.xcresult`で両端末とも成功しています。撮影した画像は[screenshots](screenshots)に保存しています。
