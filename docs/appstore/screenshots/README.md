# 画面素材

2026年9月28日、最終ビルドのXCUITestから書き出した無加工の画面です。

- `iphone-*.png`：iPhone 17 Pro Max、1320 × 2868 px。アラビア文字・ペルシャ文字・注音のガイド。
- `ipad-arabic.png`、`ipad-persian.png`、`ipad-zhuyin.png`：iPad Pro 13インチ、2064 × 2752 px。
- `ipad-landscape.png`：iPadの横画面確認用。PNGの向き情報を含むため、提出素材には上記の縦画面を使ってください。

キーボードを他のアプリで使用している画面は、実機での受け入れ確認時に追加してください。
