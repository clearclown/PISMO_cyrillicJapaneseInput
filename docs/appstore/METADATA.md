# App Store登録文案

## 日本語

名前：Pismo 日本語キーボード

サブタイトル：キリル・アラビア・ペルシャ文字と注音

説明：

使い慣れた文字で、日本語を入力。

Pismoは、キリル文字、アラビア文字、ペルシャ文字、台湾華語の注音を使って、日本語の読みを入力できるiPhone・iPad用キーボードです。入力した音をひらがなへ変換し、辞書から漢字の候補を表示します。

たとえば、アラビア文字の「نيهۆن」、ペルシャ文字の「نیهۆن」、注音の「ㄋㄧㄏㄛㄣ」から「にほん」を入力し、「日本」を選べます。

日本語入力のための独自の音の対応を使います。原語の文章を翻訳するアプリではありません。アプリ内のガイドで入力例を試せます。

・キーボード上で文字の配列を切り替え
・かな・漢字の候補表示とライブ変換
・オフラインの辞書・Zenzaiによる変換
・ユーザ辞書、着せ替え、入力のカスタマイズ
・基本入力はフルアクセス不要

通常の入力内容は端末内で処理します。誤変換レポートや単語提案は、利用者が確認して送る任意の機能です。

iOSの設定からPismoキーボードを追加して使います。パスワード欄や、他社キーボードを許可していないアプリではiOS標準キーボードが使われます。

キーワード：日本語,キーボード,かな,漢字,キリル文字,アラビア文字,ペルシャ文字,注音,台湾,入力

更新内容：アラビア文字・ペルシャ文字・台湾華語の注音による日本語入力を追加。キーボード内の配列切り替えと入力ガイドを追加し、連続入力時の処理を修正しました。

## 審査メモ（英語）

Pismo includes an iOS custom keyboard extension and a containing app with setup, settings, an offline privacy policy, and an interactive phonetic input guide. No account or login is required.

Enable Pismo in Settings > General > Keyboard > Keyboards > Add New Keyboard. Full Access is optional; the core keyboard works without it. In the keyboard's top bar, tap the character bubble button and select Arabic, Persian, or Taiwanese Zhuyin. The globe key switches to the next system keyboard.

To test: enter نيهۆن (Arabic), نیهۆن (Persian), or ㄋㄧㄏㄛㄣ (Zhuyin). The reading is にほん. Select 日本 from the conversion candidates. These are Pismo-specific phonetic input conventions, not translation of Arabic, Persian, or Mandarin sentences. The app's Settings includes a guide with examples and a practice field.

All ordinary typing and conversion run locally. Optional conversion reports and word suggestions send only the content the user chooses to submit. Privacy details are available in the app's Settings. The keyboard extension does not launch other apps apart from Settings.
